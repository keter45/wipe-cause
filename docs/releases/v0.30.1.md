## Português

- Evolução: os bosses ficam numa linha por dificuldade (Mythic, Heroic...) e, em cada uma, na ordem da raide.
- As notas agora usam as cores dos parses do Warcraft Logs: cinza, verde, azul, roxo, laranja (95–98), rosa (99) e dourado (100).
- O melhor pull de cada noite na Evolução mostra a fase ("P3 82%"), como o resumo da noite.

## English

- Progress: bosses are now in one row per difficulty (Mythic, Heroic...), each in raid order.
- Scores now use Warcraft Logs parse colors: gray, green, blue, purple, orange (95–98), pink (99) and gold (100).
- Each night's best pull in Progress shows the phase ("P3 82%"), like the night summary.
