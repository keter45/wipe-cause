## Português

- The Coiled Altar (Mítico): quando os dois fantasmas andaram até se encostar (Malevolent Resonance), a culpa agora vai só para quem andou por último. O outro já estava parado quando foi alcançado, e o texto explica: "deixou o fantasma andar ~18 jd, mas ele parou 6,9s antes; o de … andou por último e encostou nele". Se os dois pararam juntos (até 1s de diferença), os dois continuam culpados.
- Para uma noite já analisada: use "Reanalisar o log".

## English

- The Coiled Altar (Mythic): when both ghosts walked until they touched (Malevolent Resonance), the blame now goes only to whoever walked last. The other ghost had already stopped when it was reached, and the text explains it: "let their ghost walk ~18 yd, but it stopped 6.9s before; …'s walked last and touched it". If both stopped together (within 1s), both are still blamed.
- For a night already analyzed: use "Re-analyze the log".
