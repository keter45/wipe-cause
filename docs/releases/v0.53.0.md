## Português

- "O que mais pesou": cada erro com habilidade ganha o botão ▶ Replay, que abre o replay alguns segundos antes de quando aconteceu.
- Defensivos revisados pelo patch atual: Mirror Image, Greater Invisibility, Lichborne e Fade não contam mais como defensivo (não reduzem dano), e Renewing Blaze não conta em dobro com o Obsidian Scales. A Gravidade das mortes já mostra assim; nas mecânicas das noites salvas, reanalise pela Evolução.
- Recurso experimental (escondido por padrão): melhorias no compartilhamento.

## English

- "What weighed most": each mistake with an ability gets a ▶ Replay button that opens the replay a few seconds before it happened.
- Defensives reviewed for the current patch: Mirror Image, Greater Invisibility, Lichborne and Fade no longer count as defensives (they don't reduce damage), and Renewing Blaze no longer counts twice with Obsidian Scales. Death severity already shows it this way; for the mechanics of saved nights, reanalyze from Progress.
- Experimental feature (hidden by default): sharing improvements.
