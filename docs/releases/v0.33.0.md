## Português

- Desempenho: o jogador agora é escolhido em cartões agrupados por papel (Tanks, Healers, DPS), com ícone da classe, nome na cor da classe, spec e item level, no lugar da lista longa. O escolhido fica marcado na cor da classe.
- Site: um link abre direto um pull do Warcraft Logs, como `https://keter45.github.io/wipe-cause/?report=<código>&fight=<id>` (com o Warcraft Logs conectado). Sem `fight`, abre no resumo da noite. Bom para o pull postado no Discord ou na página da guilda.
- Parse do Warcraft Logs: quem é de reino com espaço no nome (como Area 52) não ganhava parse na tabela de Jogadores nem na nota. Agora ganha. Os kills já salvos sem essas pessoas são buscados de novo uma vez.
- Obrigado ao phenomzzz pelos PRs.

## English

- Performance: the player is now picked from cards grouped by role (Tanks, Healers, DPS), with class icon, name in class colour, spec and item level, instead of the long list. The picked one is outlined in its class colour.
- Website: a link opens a Warcraft Logs pull directly, like `https://keter45.github.io/wipe-cause/?report=<code>&fight=<id>` (with Warcraft Logs connected). Without `fight`, it opens the night summary. Handy for the pull posted on Discord or the guild page.
- Warcraft Logs parse: players on realms with a space in the name (like Area 52) got no parse in the Players table or the score. Now they do. Kills already saved without them are fetched again once.
- Thanks to phenomzzz for the PRs.
